## Glossário

| Termo | Significado neste projeto |
|---|---|
| Carta | Cada peça do tabuleiro; tem uma face (símbolo) e um verso |
| Par | Duas cartas com o mesmo símbolo |
| Jogada | Ato de virar **duas** cartas em sequência (conta 1 jogada) |
| Tabuleiro | Grade de cartas exibida na tela de jogo |
| Dificuldade | Define o número de pares (Fácil, Médio, Difícil) |
| Tema | Conjunto de símbolos usados nas cartas (Animais, Frutas, Transportes) |
| Recorde | Melhor resultado salvo localmente, por dificuldade |
| Estrelas | Nota de 1 a 3 calculada a partir das jogadas |
